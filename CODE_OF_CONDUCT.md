# Code of conduct

ERP-02 contributors, maintainers and automated agents acting for them work together respectfully.

- Be considerate and constructive: review the change, not the person; explain the reason behind a request.
- Assume good intent, ask before concluding, and accept that the owning repository decides within its scope.
- No harassment, discrimination, personal attacks, sexualised language or publishing others' private information.
- Keep confidential data private: never paste credentials, personal data or customer data into issues, pull requests or logs.

Report unacceptable behaviour privately to the organization owners (for a security matter, follow [SECURITY.md](SECURITY.md)). Reports are handled confidentially; the owners may edit or remove contributions and restrict access of anyone who does not follow this code.

This code applies in every ERP-02 repository and project space. It is adapted from the principles of the [Contributor Covenant](https://www.contributor-covenant.org/).
